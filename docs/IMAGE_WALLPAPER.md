# 画像壁紙

## 使い方

1. 設定画面の「画像を選ぶ」でPNG・JPEGファイルを選びます。
2. プレビューを見ながら表示方法と背景色を調整します。
3. 「時計をデスクトップに表示」でプライマリ画面へ表示します。表示中の変更も即時反映します。
4. 「画像を外す」で単色背景に戻します。時計の初期設定ボタンは背景を変更しません。

画像の場所・表示方法・背景色は時計と同じsettings.jsonに自動保存します。旧バージョンの時計だけの設定も読み込めます。起動時は設定とプレビューを復元し、デスクトップ表示はボタンで開始します。

## 表示とエラー処理

- 全面に広げる: 縦横比を保ち、画面からはみ出す部分を中央で切り抜きます。
- 画像全体を表示: 縦横比を保ち、余白に背景色を表示します。
- 引き伸ばす: 縦横比を変えて画面全体に合わせます。
- PNGの透明部分は背景色になります。
- 選んだファイルはコピーしません。移動・削除・破損などで復元できない場合、背景色で表示して選び直しを案内します。
- 新しい画像の読み込みに失敗しても、現在の画像と保存済みの選択は保持します。キャンセルでも変更しません。
- 画像選択・読み込み中の重複操作を防ぎ、終了後の非同期処理は画面へ反映しません。

WallpaperSurfaceで背景と時計を合成し、プレビューとデスクトップで同じ部品を使用します。画像は長辺が4096ピクセルを超える場合に縮小してデコードし、同じBitmapImageを共有します。元ファイルは変更しません。現時点では静止画のみ対応します。

## 二重起動防止

AppInstanceへの登録を設定読み込みとMainWindow作成より先に行います。2回目の起動は既存プロセスへ起動通知を転送して終了し、既存画面を復元・表示します。登録や通知に失敗した場合は説明を表示して終了します。

旧版にはこの仕組みがないため、更新前に旧版を終了してください。「アプリを終了」では設定の保存、時計・壁紙ウィンドウの終了、タイマーの停止、トレイアイコンの削除を行います。×は設定画面だけを隠します。

## 検証範囲

自動テストでは画像設定の保存・復元・解除・バックアップ、時計だけの旧形式、不正値の補正を確認します。CIでは配布版の連続起動・同時起動・通常終了を確認します。

実画面での画像選択・表示確認は別途必要です。確認項目は以下です。

- 横長・縦長・透過PNG・JPEGが3種類の表示方法で正しく見える。
- 時計の文字色や位置を変えても背景を保持し、デスクトップアイコンを操作できる。
- 画像選択のキャンセル・破損画像で現在の背景が消えない。
- 再起動で設定を復元し、元画像を移動した場合に背景色と案内が出る。
- 最小化して再起動すると設定画面が復元され、時計が重複しない。
- 「アプリを終了」で時計と画像が消え、元のWindows壁紙に戻る。
