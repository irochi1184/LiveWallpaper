# タスクトレイ常駐

設定画面の×は画面だけを隠し、表示中の時計・画像を続けます。設定画面を開くにはトレイアイコンをクリックするか、LiveWallpaperを再起動します。二重起動は既存の画面へ転送されます。

トレイの右クリックメニューは「設定を開く」「LiveWallpaperを終了」です。キーボードによる選択・メニュー表示も処理します。Windowsの設定によってアイコンは隠れているインジケーター内に入ることがあります。現在は標準のアプリケーションアイコンを使用します。

設定画面の「アプリを終了」でも完全に終了できます。終了では未保存の変更を保存してから壁紙・タイマー・トレイを破棄します。保存に失敗した場合は設定画面を残し、再試行を案内します。常駐中はプレビュー用タイマーを止め、画面を開いたときに再開します。

トレイ登録に失敗した場合は説明を表示し、×で通常終了します。Explorerが再起動した際のTaskbarCreated通知ではアイコンを再登録し、失敗時は設定画面を開きます。壁紙の接続が失われた場合も設定画面へ戻して再表示を案内します。壁紙自体の自動復帰は今後の対応です。

実装はWindows層のTrayIcon（Shell_NotifyIconW / SetWindowSubclass）と、MainWindowの表示・終了管理に分けています。ネイティブコールバックからはDispatcherQueueへ処理を送って、コールバック実行中にウィンドウを破棄しないようにします。

検証: 2026-09-27、Windows実機でトレイ登録成功、×で設定画面が消えてプロセスが生存、再起動で同じPID/HWNDが復帰、明示的な終了でプロセスが消えることを確認しました。トレイメニューの直接操作・Explorer再起動・OS終了は未確認です。CIはExplorerがある環境で常駐と復帰を検証し、通知領域のない環境では×による通常終了へのフォールバックを検証します。

参考: [Microsoftの通知アイコンAPI](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyiconw)。
